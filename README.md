# BMI Calculator - Oasis Infobyte Task 2

A modern, dark-themed Body Mass Index (BMI) calculator built with Python's Tkinter library. This application provides real-time BMI calculation and visual category categorization (Underweight, Normal, Overweight, Obese) using color-coded outputs.

## Features
* **Modern GUI:** Clean, distraction-free dark theme interface.
* **Instant Calculation:** Converts height (cm) and weight (kg) to compute precise BMI.
* **Dynamic Feedback:** Color-coded text feedback based on international health standards.
* **Error Handling:** Gracefully catches non-numeric inputs and invalid numbers.

## How to Run
Ensure you have Python installed. No external libraries are required.
```bash
python bmi_calculator.py
