# Oasis Infobyte Python Development Internship (OIBSIP) 🚀

Welcome to my repository! This workspace contains all the graphical user interface (GUI) Python projects developed during my 1-month virtual internship at **Oasis Infobyte**. 

## 📂 Projects Completed

This repository is structured into separate folders for each task. Each project includes its own source code and detailed documentation.

* **[Task 2: BMI Calculator](./Python-Task2-BMICalculator)** 
  A health utility app that calculates Body Mass Index based on user input, featuring robust error handling and an intuitive dark-themed UI.
* **[Task 3: Password Generator](./Python-Task3-PasswordGenerator)** 
  A security tool to generate strong, customizable passwords of varying lengths with a built-in 1-click 'Copy to Clipboard' feature.
* **[Task 4: Weather App](./Python-Task4-WeatherApp)** 
  A real-time weather tracking application that fetches live climate data (temperature, humidity, wind speed) from the OpenWeatherMap API.

## 🛠️ Tech Stack Used
* **Language:** Python 3
* **GUI Framework:** Tkinter
* **APIs & Libraries:** `requests`, `json`, `random`, `string`
