# BMI Calculator (Task 2)

A simple GUI-based Body Mass Index (BMI) calculator built using Python and Tkinter for the Oasis Infobyte Internship.

## Features
- Calculates BMI instantly based on height and weight inputs.
- Displays standard health categories (Underweight, Normal, Overweight, Obesity).
- Simple, dark-themed graphical interface.
- Includes basic error handling for invalid inputs.
