# Weather App (Task 4)

A simple GUI-based Weather application built using Python and Tkinter for the Oasis Infobyte Internship. It fetches real-time weather data using a live API.

## Features
- Fetches and displays live weather data (temperature, humidity, wind speed) for any city.
- Simple and intuitive graphical interface.
- Built using Python's `requests` library to handle API calls.
- Includes basic error handling for invalid city names or network issues.

## Prerequisites
You need to install the `requests` library before running the app. Run this command in your terminal:
```bash
pip install requests
